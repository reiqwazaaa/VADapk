# Kotoba 0.1.2 — расшифровка и перевод для ПК

Настольное приложение с русским интерфейсом. Принимает видео или аудио, распознаёт речь локально, переводит и автоматически сохраняет TXT и SRT в выбранную папку. Русский, английский и японский доступны во всех шести направлениях. Можно оставить тот же язык или выбрать «Только расшифровка».

## Запуск на Windows 10/11 x64

1. Распакуй архив полностью в обычную папку, например `D:\Apps\Kotoba`.
2. Установи **Python 3.11 x64** с [python.org](https://www.python.org/downloads/windows/). При установке оставь включённым **Python Launcher** и поддержку Tcl/Tk. Если Python уже установлен: `py -3.11 --version` должен показать версию 3.11.
3. Запусти **install.bat** и дождись сообщения `Done`. Интернет нужен для установки библиотек.
4. Для RTX 3070 запусти **install-gpu.bat**. Он установит библиотеки CUDA 12 / cuDNN 9 внутрь приложения. Обнови драйвер NVIDIA; отдельный CUDA Toolkit ставить не нужно.
5. Открывай приложение через **start.bat**. Первый запуск покажет варианты моделей и рекомендации.
6. Выбери файл, папку результата, два языка, модель и переводчик. Нажми «Распознать и сохранить».

Не запускай BAT прямо внутри ZIP. Администратор для скриптов не нужен. Модели в архив не включены: выбранные модели скачиваются автоматически при первой задаче. Интернет и свободное место понадобятся заранее. Для начала оставь 8–12 ГБ свободного места на диске под окружение и модели. В зависимости от числа моделей может понадобиться больше.

Готовая переносимая сборка находится в отдельном архиве `Kotoba-Windows.zip`: распакуй всю папку и запусти `Kotoba.exe`. Python и CUDA-библиотеки включены. EXE проверен через Wine: окно, загрузка библиотек, генерация движка перевода и реальное распознавание аудио. Настоящая Windows/RTX здесь недоступны; скрипты BAT не прогонялись на реальной Windows.

## Что выбрать для RTX 3070 8 ГБ / 16 ГБ RAM

| Модель Whisper | Рекомендация | Загрузка, примерно |
|---|---|---|
| large-v3-turbo | Начни здесь: баланс для русского, английского, японского | 1,6 ГБ |
| large-v3 | Попробуй для сложного японского/русского; медленнее | 3,1 ГБ |
| medium | Меньше памяти, промежуточное качество | 1,5 ГБ |
| small | Скорость, особенно английский; подходит для CPU | 0,5 ГБ |

Используется faster-whisper/CTranslate2. На CUDA — `int8_float16`, на CPU — `int8`, без пакетной обработки. `auto` выбирает GPU при наличии доступного устройства CUDA. Это рекомендации, а не измерения на RTX 3070. Фактическая VRAM зависит от других приложений и записи. Если возникает ошибка CUDA/памяти: закрой игры, попробуй medium, проверь установку GPU-компонентов или выбери `cpu`.

Для японского вручную укажи `日本語` как язык речи. Модели универсальные; качество зависит от дикции, музыки и шумов. Здесь нет разделения по говорящим и ручного редактора субтитров. Таймкоды даёт Whisper; перевод сохраняет исходные границы фраз и не выравнивает длину строк под скорость чтения.

## Перевод

- **Офлайн NLLB-200 distilled 600M.** Скачивается примерно 2,5 ГБ, затем работает локально на CPU. Whisper освобождается перед загрузкой переводчика, чтобы уменьшить пиковую память. На CPU перевод может быть медленным; это перевод отдельных фраз без контекста всего фильма. Модель [facebook/nllb-200-distilled-600M](https://huggingface.co/facebook/nllb-200-distilled-600M) имеет лицензию **CC-BY-NC 4.0**: учитывай ограничение на коммерческое применение модели.
- **Google Cloud Translation API v2.** Нужен ключ проекта с включённым Cloud Translation API и необходимым биллингом/квотой. [Документация](https://cloud.google.com/translate/docs/setup). Обычная учётная запись Google Translate сама по себе ключа API не даёт.
- **DeepL API.** Нужен ключ тарифа DeepL API Free или Pro. Для Free оставь галочку, для Pro сними. [Документация](https://developers.deepl.com/docs/getting-started/intro).

Онлайн-сервисы получают **текст расшифровки**; аудиофайл не отправляется. Приложение не сохраняет ключ API в настройках или журналах. Тарифы/доступность сервисов зависят от их условий. При сетевой ошибке автоматического переключения провайдера нет.

Для полностью локальной работы сначала выполни задачу с нужными моделями, затем включи «Строго офлайн». В этом режиме скачивание запрещено; если модель отсутствует в выбранном хранилище, задача сообщит об ошибке. Не меняй папку моделей на пустую после загрузки, если хочешь использовать кэш.

## Файлы результата

Для каждой задачи создаётся отдельная подпапка, например:

```
D:\Subtitles\my-video_ab12cd34\
  my-video.ja.txt
  my-video.ja.srt
  my-video.ru.txt
  my-video.ru.srt
```

TXT/SRT сохраняются в UTF-8 с BOM для совместимости с Windows. Исходная расшифровка сохраняется **до перевода** и остаётся при сбое перевода. При одинаковых языках/без перевода создаются только два исходных файла. Старые задачи не перезаписываются. Папка задачи создаётся после получения первой фразы. При сбое модели пустая подпапка больше не остаётся.

«Отменить» останавливает обработку на границе фрагментов. Текущий расчёт, загрузка модели или запрос API могут завершиться не сразу (HTTP-запрос имеет тайм-аут). Во время задачи интерфейс остаётся доступным, настройки заблокированы. Для выхода сначала дождись отмены/завершения.

Поддержка форматов обеспечивается PyAV/FFmpeg внутри библиотеки: MP4, MKV, WebM, MOV, MP3, WAV, FLAC, M4A и другие. Отдельный `ffmpeg.exe` для обычной работы не нужен. Для контейнера с несколькими аудиодорожками берётся дорожка по умолчанию; выбора дорожки пока нет. DRM/повреждённые файлы не поддерживаются. Загрузка видео по URL в эту версию не входит.

Настройки и модели по умолчанию: `%LOCALAPPDATA%\Kotoba`. Папку моделей можно выбрать в окне. Последняя папка результата, языки и модель запоминаются; ключи API — нет.

## Сборка EXE

На Windows после установки запусти `build-exe.bat`. Результат — папка `dist\Kotoba` с `Kotoba.exe` и библиотеками. Переносить нужно всю папку. Модели всё равно загружаются отдельно. Это не single-file EXE: Torch/CUDA делают сборку большой. Сборка выполнена в этой Linux-среде через Windows Python/Wine; итоговый EXE проверен. Сборка использует `Kotoba.spec`, исключающий ненужные статические архивы Torch и сохраняющий нужные runtime-модули.

Также приложен `.github/workflows/windows.yml`: положи содержимое папки Kotoba в корень своего репозитория, затем Actions → Build Windows desktop → Run workflow. После успешной сборки скачай артефакт Kotoba-Windows. Workflow здесь не запускался, репозиторий автоматически не создавался.

## Разработка / Linux

Python 3.11 рекомендуется. На Linux нужен системный tkinter и рабочий графический дисплей.

```sh
python3 -m venv .venv
.venv/bin/pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m kotoba
.venv/bin/python -m unittest discover -s tests -v
```

Зависимости закреплены для совместимости: PyAV 16.0.1 используется потому, что у новой PyAV изменился API, который вызывает faster-whisper 1.2.1. CUDA-библиотеки на Linux устанавливаются отдельно с настройкой путей загрузчика. Автоматическое добавление DLL в приложении реализовано для Windows.

## Исправления сохранения в 0.1.1

Имена папок/файлов сокращаются с учётом длины пути Windows. После записи приложение читает TXT/SRT обратно и проверяет содержимое; успех показывается только после проверки файлов на диске. Исходная расшифровка по-прежнему сохраняется до перевода.

Кнопка «Журнал» открывает полный лог текущей задачи. Логи хранятся в `%LOCALAPPDATA%\Kotoba\logs`; API-ключи скрываются перед записью. В логе указаны полный путь сохранения, этап работы, размеры файлов и подробная ошибка. Лог окна очищается при запуске новой задачи.

## Защита распознавания в 0.1.2

Whisper выполняется в отдельном процессе. Исходные TXT/SRT появляются после первой фразы и обновляются каждые 25 фраз или примерно раз в 2 секунды. При аварийном завершении worker полученный текст остаётся в выбранной папке, а окно приложения продолжает работать. Незавершённая расшифровка отмечается ошибкой и не переводится автоматически.

Модель CUDA не уничтожается в процессе интерфейса: после подтверждённого завершения отдельный worker завершает работу, ресурсы освобождает ОС. Это исключает потерю всей расшифровки при сбое нативного движка или его очистки. Последний таймкод ограничивается реальной длительностью аудио.
