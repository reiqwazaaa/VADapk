# Kotoba Windows x64 — сборка 17 ноября 2026

Приложение собрано Windows Python 3.11.9 и PyInstaller 6.16.0 через Wine 10.

Включены: faster-whisper 1.2.1, CTranslate2 4.6.0, Torch 2.6.0 CPU для NLLB,
Transformers 4.57.1, PyAV 16.0.1, ONNX Runtime, SentencePiece, Tokenizers,
CUDA runtime 12.9.79, cuBLAS 12.9.1.4 и cuDNN 9.10.2.21 x64,
необходимые библиотеки Microsoft Visual C++ 2015–2022.

Whisper ускоряется через CTranslate2/CUDA; CPU-версия Torch используется для
локального переводчика, чтобы экономить видеопамять.

Проверено в собранном EXE, со скрытой установкой сборочного Python:

- Открытие окна, 14 элементов настройки, адаптация размера окна.
- Загрузка faster-whisper, CTranslate2, Torch, Transformers, PyAV,
  ONNX Runtime, SentencePiece, модели M2M100 и токенизатора NLLB.
- Реальная генерация токенов миниатюрной конфигурацией M2M100 — архитектурой NLLB.
  Это проверка исполнения движка, без загрузки весов 600M в этот прогон.
- Реальное распознавание 11-секундной записи JFK через Whisper tiny/int8,
  включая VAD, и запись TXT/SRT. Полученные файлы прочитаны и проверены.
  Для Wine кэш HF материализован обычными файлами из скачанных blobs,
  поскольку создание symlink в этом Wine-префиксе не создавало файлы snapshot.
- Повторная проверка импортов и генерации после добавления CUDA-библиотек.
- PE x64 заголовок EXE и всех включённых NVIDIA DLL.
- Девять автоматических тестов приложения в Windows Python через Wine.

Ранее исходная версия прошла реальные прогоны аудио/MP4 и все шесть
направлений NLLB RU/EN/JA на Linux CPU. Полные веса Whisper/NLLB в ZIP не включены.

Настоящая Windows и GPU в этом окружении недоступны: скорость RTX 3070,
VRAM и выполнение CUDA на видеокарте здесь не проверялись. Онлайн Google/DeepL
проверялись контрактными тестами с имитацией ответов, без платных запросов.
