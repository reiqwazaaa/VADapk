# VAD для Android (APK)

Приложение: вставляете ссылку (или нажимаете «Поделиться» в браузере и выбираете VAD),
выбираете качество или формат, жмёте «Скачать». Файлы падают в `Загрузки/VAD`.
Движок: yt-dlp + ffmpeg (библиотека youtubedl-android), поддерживает большинство сайтов.

Возможности: авто-режим (FHD / HD / максимум), выбор видео- и аудиоформата вручную,
MP3, плейлисты, обновление yt-dlp кнопкой, свой прокси (socks5://… от ByeDPI/VPN), отмена.

Конвертер (кнопка на главном экране): выбор нескольких файлов, перевод в mp3, flac, ogg, opus, m4a, aac, wav, wma, mp4, mkv, webm, avi, mov, gif, webp
с выбором качества и максимальной высоты; результат падает в `Загрузки/VAD/Converted`.

Читалка (кнопка на главном экране): PDF, DOCX, PPTX, EPUB, FB2 (и FB2.ZIP), HTML, TXT, MD; комиксы и манга:
CBZ, CBR (RAR4), CB7, CBT, ZIP/RAR/7Z, папка с картинками или несколько картинок сразу. Для комиксов: зум щипком и двойным тапом,
листание тапами по краям, свайпом и кнопками громкости, режим манги (справа налево), по ширине / по странице.
Для текстов: размер шрифта, светлая / сепия / тёмная тема. Место чтения запоминается.

## Как получить APK (без Android Studio)

1. Создайте на github.com пустой репозиторий (можно приватный).
2. Загрузите в него всё содержимое этой папки (Add file → Upload files; папка `.github` тоже!).
3. Откройте вкладку **Actions** → «Build APK» → дождитесь зелёной галочки (5-10 минут).
4. Внутри запуска, раздел **Artifacts** → `VAD-apk` → скачайте ZIP, внутри `app-debug.apk`.
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

## Сборка вручную (Android Studio / командная строка)
`gradle assembleDebug`: APK появится в `app/build/outputs/apk/debug/`.
Нужны JDK 17 и Android SDK 34.

## Мини-игры и меню «Игры»
- Перед скачиванием запускается случайная мини-игра (`app/src/main/assets/games/<id>`): змейка, лабиринт, платформер, тетрис, арканоид, захватчики, звёздный истребитель, танки (клон Battle City), «Мат в 2 хода» (16 задач).
- Кнопка «⋯» рядом с настройками → «Игры»: шахматы с Юта-тян (3 уровня), бесконечные змейка и тетрис, кампания «Танки» из 6 уровней (`assets/free/<id>`). Рекорды и прогресс хранятся через `G.save/G.load`.
- Формат игры описан в `assets/games/template`; игры можно править в режиме разработчика.
- Всё проверено в headless Chromium (Playwright) и сборкой CI; на реальном устройстве не тестировалось.
